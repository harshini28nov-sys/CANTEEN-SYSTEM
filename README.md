# Canteen Manager 🍽️

A web application for managing canteen food orders, menus, stock, offers, and payments.

## Features
- Student food ordering
- Digital token generation
- Staff order management
- Menu and stock management
- Special offers
- Sales reports
- Online payments using Razorpay
- Mobile-friendly website

## Technologies Used
- HTML, CSS, JavaScript
- Node.js
- Razorpay
- GitHub

## How to Run
1. Install Node.js (version 18 or newer).
2. Open the project folder in a terminal.
3. Run `node server.js`.
4. Open `http://localhost:3000`.

## Deployment
Deploy the project using Render and connect your GitHub repository.
